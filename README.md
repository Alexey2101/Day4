# Аналитика интернет-магазина (День 4)

Интерактивный веб-дашборд на **Streamlit** и **Plotly** для анализа данных продаж из базы SQLite (`shop.db`).

## Структура проекта

- `dashboard.py` — основное приложение Streamlit с фильтрами, показателями, графиками, таблицей и экспортом CSV.
- `shop.db` — база данных SQLite с таблицей `sales` (`id`, `product`, `category`, `price`, `quantity`, `sale_date`).
- `README.md` — инструкция по установке и запуску.

## Возможности дашборда

- **Фильтрация данных** в боковой панели (`st.sidebar`) по категориям и товарам (`st.multiselect`).
- **Ключевые показатели (`st.metric`)**, автоматически пересчитываемые по фильтрам:
  - Общая выручка (`₸`);
  - Продано товаров;
  - Количество записей;
  - Средняя цена (`₸`).
- **Интерактивные графики (`plotly.express`)**:
  - Столбчатая диаграмма выручки по товарам (`px.bar`);
  - Круговая диаграмма доли выручки по категориям (`px.pie`);
  - Линейный график динамики выручки по датам (`px.line`).
- **Таблица продаж** (`st.dataframe`) и сообщение при пустом результате фильтрации.
- **Экспорт отчёта в CSV** (`sales_report.csv` в кодировке `utf-8-sig`) по кнопке **«Скачать CSV»**.

## Требования и установка

Убедитесь, что установлен Python 3 и необходимые библиотеки:

```bash
python -m pip install streamlit pandas plotly
```

## Запуск приложения

Перейдите в папку проекта (`Day4`) и выполните одну из команд:

```bash
streamlit run dashboard.py
```

Если команда `streamlit` не распознаётся в `PATH`, используйте запуск через модуль Python:

```bash
python -m streamlit run dashboard.py
```

После запуска дашборд откроется в браузере.
Для остановки нажмите `Ctrl + C` в терминале.
